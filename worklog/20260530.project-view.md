# 工作總結：新增專案概覽模式

## 時間戳記
2026-05-30

## 問題描述
用戶要求在現有任務欄之外，建立一個獨立的彈出視窗，以階層式樹狀結構對所有 `+project` 進行概覽，支援已完成/未完成任務混排、多行描述展開收合、一鍵跳轉回主視圖。

## 修改的檔案

### `index.html`
- **CSS** — 新增 `.project-view-box`, `.pv-node`, `.pv-project-header`, `.pv-toggle`, `.pv-project-name`, `.pv-count`, `.pv-children`, `.pv-task-item`, `.pv-jump-btn` 等樣式
- **HTML** — Header 新增 `📋` 按鈕（`#btn-project-view`）；新增 `#project-view-modal` Modal 結構
- **JS** — 新增 9 個函數：
  - `openProjectView()` — 建立專案樹、排序、渲染
  - `closeProjectView()` — 關閉視窗
  - `renderProjectViewTree()` — 遞迴渲染階層
  - `buildProjectViewItem()` — 渲染單一任務（唯讀，含標籤 + 收合描述 + 跳轉按鈕）
  - `countAllTasks()` — 遞迴計算包含子節點的任務總數與未完成數
  - `toggleProjectViewChildren()` — 展開/收合節點
  - `toggleProjectViewDescriptions()` — 按專案名展開/收合所有描述
  - `toggleAllProjectViewNodes()` — 一鍵全部展開/收合
  - `jumpToTask()` — 關閉概覽、跳轉到主視圖並高亮
  - `checkProjectViewDescOverflow()` — 檢查描述是否需要展開按鈕
- **DOM Cache** — 新增 `project-view-modal`、`project-view-content`
- **i18n 按鈕標題** — 新增 `btn-project-view`
- **Public API** — 匯出所有新函數

## 功能要點
1. 點擊 Header `📋` 按鈕彈出 Modal，以階層樹狀組織所有 `+project`
2. 已完成/未完成任務均顯示，排序沿用主視圖規則
3. 專案名稱旁顯示進度計數：`((總數/未完),(直屬數,直屬未完))`
4. ▶/▼ 箭頭切換子節點，按專案名稱切換所有描述
5. `🔽` 按鈕一鍵全部展開/收合
6. 每個任務有 `↗` 跳轉按鈕，返回主視圖並高亮
7. 多行描述預設收合，點擊展開/收起
8. 無專案任務歸類在「未分類」
