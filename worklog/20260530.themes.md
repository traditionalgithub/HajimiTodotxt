# 工作總結：新增柔和配色主題（兩批次）

## 時間戳記
2026-05-30

## 問題描述
原有 7 個主題（neutral/dark/girly/solarized-light/nord-light/solarized-dark/nord-dark）中，亮色主題選擇較少，暗色主題偏硬，缺少柔和護眼的配色方案。

## 解決方案
兩批次共新增 16 個柔和配色主題（12 亮色 + 4 暗色），使用低飽和度、暖色調、減少對比刺激的配色策略：

### 第一批 — 8 主題（4 亮 + 4 暗）
| 主題 | 色調 | 設計理念 |
|------|------|----------|
| `sakura` (櫻花粉) | 粉嫩玫瑰色 | 極淺粉底 + 柔和玫瑰文字，溫柔不刺眼 |
| `mint` (薄荷綠) | 清新薄荷色 | 淺綠底色 + 墨綠文字，清新舒目 |
| `lavender` (薰衣草紫) | 淡雅紫色 | 淺紫底色 + 深紫文字，優雅寧靜 |
| `peach` (蜜桃橙) | 溫暖蜜桃色 | 淺橙底色 + 暖棕文字，溫潤如蜜 |
| `dim` (柔暗灰) | 柔和深灰 | 非純黑底色 + 柔光灰文字，比 dark 更護眼 |
| `forest` (森林夜) | 暗綠色 | 深墨綠底色 + 淺灰綠文字，森林般寧靜 |
| `twilight` (暮光紫) | 暗紫色 | 深紫底色 + 淺紫文字，深邃柔和 |
| `cocoa` (可可棕) | 暖棕色 | 深棕底色 + 暖灰文字，溫潤不傷眼 |

### 第二批 — 8 亮色主題
| 主題 | 色調 | 設計理念 |
|------|------|----------|
| `cream` (奶油白) | 暖奶油色 | 暖白底色 + 暖棕文字，比 neutral 更柔和溫潤 |
| `sky` (天空藍) | 清新天空藍 | 淺藍底色 + 深藍文字，清爽平靜 |
| `matcha` (抹茶綠) | 大地抹茶綠 | 淺黃綠底色 + 墨綠文字，天然樸實 |
| `linen` (亞麻灰) | 亞麻灰褐 | 暖灰底色 + 灰褐文字，自然織物質感 |
| `honey` (蜂蜜金) | 溫暖蜂蜜金 | 淺金色底 + 深棕文字，溫暖如蜜 |
| `seafoam` (海沫藍) | 海洋泡沫藍綠 | 淺藍綠底色 + 墨綠文字，清涼舒暢 |
| `cloud` (雲朵灰) | 雲朵暖灰 | 淺暖灰底色 + 深灰文字，簡潔乾淨 |
| `coral` (珊瑚粉) | 柔和珊瑚粉 | 淺珊瑚底色 + 暖棕文字，介於粉與橙之間 |

## 修改的文件
- `index.html` — 新增 16 組 `[data-theme]` CSS 變數區塊 + 下拉選單中新增 16 個選項
- `lang/zh-TW.json` — 新增 16 組主題翻譯鍵值
- `lang/en.json` — 新增 16 組主題翻譯鍵值
- `SPEC.md` — 更新 6.4 主題列表（7→23 個）
- `REPLICA.md` — 更新 9.6 主題表格、14.3 主題數量、附錄 B 行數
- `REWORK.md` — 更新 1.1 主題系統數量、8.5 主題數量

## 技術細節
- 完全沿用既有 CSS 變數系統，無需改動 JS 邏輯
- 所有主題共用同一組 CSS 變數名稱（`--bg-color`, `--text-color` 等）
- 亮色主題統一使用 `#66bb6a` 作為 success 色、`#e57373` 作為 danger 色
- 暗色主題統一使用 `#69f0ae` 作為 success 色
- 不需要修改 `applyTheme()`、`loadConfig()`、`saveConfig()` 等 JS 函數
