# 2026-11-24 編輯視窗排版精簡與新標籤透明修正

- 施做時間：2026-11-24 16:31 CST
- 涉及版本：HajimiTodotxt v8.6

## 問題描述

1. 編輯視窗「任務屬性」分頁中，優先級下拉選單獨自佔滿一列（`flex-1`），但選項只有一個字母（A–Z），空間浪費；而 @ / + / ☀️ 三個按鈕又另佔一列，整張表顯得鬆散。優先級原本打算與三個日期欄位同一列，但會擠佔日期空間，最終改為移入按鈕列。
2. 由 @ / + 標籤選單插入新的上下文或專案到任務標題時，新插入的文字完全看不到（呈透明色）。

## 問題癥結

- 排版：`.form-row` 為 flex，`form-group.flex-1` 讓優先級與其他欄位等寬；@ / + / ☀️ 被放在獨立的一列 `btn-group` 中。
- 透明標籤：標題 textarea 與彩色覆蓋層搭配運作——`.highlight-editor.ready > textarea { color: transparent; }`，可見文字完全由 `.highlight-backdrop` 繪製。
  - 一般打字會觸發 `input` 事件並呼叫 `syncHighlightEditor()`，所以正常可見。
  - `appendTagToInput()` 直接改寫 `inp.value`，**沒有**觸發 `input`，也沒有呼叫 `syncHighlightEditor()`，覆蓋層仍是舊內容，因此新插入的標籤在透明 textarea 上完全不可見。
  - 此外覆蓋層原本只為日期 token 上色，`+專案` / `@情境` 都是純文字，延續了「標籤只是普通文字」的觀感。

## 解決原理與思路

### 排版

- 將優先級與 @ / + / ☀️ 都移到「標題大小: ▲ ↺ ▼」同一列，並以 `.btn-group-divider` 分隔三組元素；移除按鈕原本 38×38 的內聯尺寸，讓該列高度一致。
- 優先級改用新的 `.pri-group`，以 `display: flex` 讓標籤與下拉選單橫排（`flex: 0 0 auto`，select 固定 52px），避免把按鈕列撐高。
- 日期列只剩截止日期、隱藏至、重複三個欄位，皆維持 `flex-1` 平均分配空間，不再被優先級擠佔。

### 透明標籤

- 在 `appendTagToInput()` 改寫 value 後呼叫 `syncHighlightEditor(inp)`，立即重繪覆蓋層；此呼叫對 `filter-input`（沒有覆蓋層）會安全提早返回。
- 為覆蓋層新增 `renderHighlightSegment()`，仿照任務列表的 `renderSubjectSegment()` 為 `+專案`（`--project-color`）與 `@情境`（`--context-color`）上色；刻意**不改字重**（不同於列表的 `font-weight: bold`），以維持覆蓋層與 transparent textarea 的像素對齊。
- 新增 `.highlight-backdrop .hl-project-tag` / `.hl-context-tag` 兩個 color-only 樣式。
