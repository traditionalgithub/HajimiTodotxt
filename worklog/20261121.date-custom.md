# 2026-11-21 編輯視窗日期三色與「指定日期…」

- 施做時間：2026-11-21 02:40 CST
- 涉及版本：HajimiTodotxt v8.5（延續 `20261121.date-ui.md`）

## 問題描述

1. 任務列表與描述中的日期已有三色標記，但編輯視窗中的截止日、隱藏至、完成日欄位仍是普通顏色。
2. 日期快速修改氣泡只有「改為今天」與「改為現在的時間」，無法指定任意日期。
3. 指定日期時，希望沿用截止日／隱藏日至相同的原生日期選擇器，而不是自行另做一套日曆。

## 解決原理與思路

### 編輯視窗日期欄位三色

- 新增 `updateDateFieldColors()`，依本地 `todayStr()` 比較 `inp-due`、`inp-t`、`inp-done-date` 的值，套用：
  - `date-field-future` → `--success`
  - `date-field-today` → `--accent`
  - `date-field-past` → `--danger`
- 顏色同時套用到文字與邊框；`::-webkit-datetime-edit { color: inherit; }` 讓 Chromium 的原生日期文字跟隨顏色。
- 開啟編輯視窗、手動變更日期、隱藏期自動修正時都會重新計算。

### 「指定日期…」按鈕

- 日期氣泡新增第三顆按鈕，文字由 i18n 的 `dateChangeToSpecific` 提供。
- 氣泡內放置一個原生 `<input type="date" id="date-action-picker">`；按鈕被點擊時切換到自訂模式，先帶入目前日期，再呼叫 `showPicker()` 開啟系統日期選擇器。
- 若瀏覽器不支援 `showPicker()`，日期輸入框仍會直接顯示，可手動點選，功能不中斷。
- 選定日期後觸發 `change`，套用至任務或 textarea；指定日期只替換日期，若原文有時刻則保留原時刻。
- 氣泡按鈕的 `mousedown` 只對按鈕 `preventDefault()`，日期輸入框可正常取得焦點；延遲隱藏計時器也會檢查焦點是否仍在氣泡內，避免操作日期選擇器時氣泡消失。

## 驗證

以 Chromium headless + CDP 實測：

- 截止日欄位依 `2099-01-01` / 今日 / `2000-01-01` 分別得到 future / today / past。
- 隱藏至與完成日欄位同樣正確套色。
- 日期氣泡按鈕為「改為今天｜改為現在的時間｜指定日期…」。
- 點「指定日期…」後，原生日期輸入框顯示、預填目前日期，且焦點在輸入框時氣泡不會消失。
- 指定 `2026-12-25` 後，標題中的 `[2026-11-21 08:30]` 變成 `[2026-12-25 08:30]`（保留時刻）。
- 描述 textarea 中 `[2020-01-02 03:04]` 指定 `2026-12-31` 後變成 `[2026-12-31 03:04]`。
- `node --check` 與中英語言檔 JSON 檢查通過。
