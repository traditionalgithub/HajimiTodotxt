# 2026-11-21 編輯視窗標題／描述輸入框的日期三色

- 施做時間：2026-11-21 16:35 CST
- 涉及版本：HajimiTodotxt v8.5

## 問題描述

任務列表與專案概覽中的日期已有未來／今日／過去三色，但打開編輯視窗後，標題與描述輸入框中的日期仍是一般文字顏色，編輯時不容易判斷日期狀態。

## 問題癥結

- 日期高亮只存在於渲染後的 HTML（`renderSubjectHtml()` / `renderDescHtml()`）。
- 編輯視窗使用原生 `<textarea>`，textarea 只能有一組文字顏色，無法對個別片段上色。
- 截止日／隱藏至等 `<input type="date">` 的顏色是欄位整體顏色，不能套用到自由文字中的日期。

## 解決原理與思路

- 採用「透明 textarea + 彩色覆蓋層」：
  - 在 textarea 外加上 `.highlight-editor` 容器，容器內放一個 `aria-hidden` 的 `.highlight-backdrop`。
  - 覆蓋層依照 textarea 的值重新產生 HTML，只把日期 token 包成 `hl-date-future` / `hl-date-today` / `hl-date-past`。
  - textarea 本身保持真正可編輯、可選取、可存檔；背景與邊框移到外層容器，文字顏色設為透明，游標顏色另外指定。
  - 只有在覆蓋層成功建立後才加上 `.ready` 讓 textarea 文字透明；若 JavaScript 失敗，文字仍會正常顯示，不會消失。
- 對齊與捲動：
  - 同步時複製 textarea 的 computed font、line-height、letter-spacing、white-space、word-break、tab-size、padding 等屬性。
  - 覆蓋層寬高設為 textarea 的 `clientWidth` / `clientHeight`，避開捲軸寬度差異。
  - textarea 捲動時同步覆蓋層 `scrollTop` / `scrollLeft`。
  - 使用 `ResizeObserver` 處理手動拖曳調整高度與切換分頁後的可見尺寸變化。
- 更新時機：
  - `input`、`change`、`compositionend`、`scroll`、視窗縮放。
  - 開啟編輯視窗、切換分頁、插入現在時間／分隔符、重新編號、今日任務開關、日期氣泡套用後都主動同步。
- 一併修正：套用日期氣泡動作後，`setSelectionRange()` 會觸發 `select` 事件而讓氣泡立刻重新弹出；加入抑制旗標，套用後保持氣泡關閉。

## 驗證

以 Chromium headless + CDP 實測：

- 標題輸入框：`2026-12-31` 綠、`2026-11-21` 主題色、`2020-01-02` 紅。
- 描述輸入框：`[2026-12-31]`、`[2026-11-21 08:30]`、`[2020-01-02 03:04]` 分別得到 future / today / past。
- 修改 textarea 值並觸發 `input` 後，覆蓋層立即更新。
- 覆蓋層與 textarea 的 `scrollHeight` / `scrollWidth` 在多行、長行、結尾換行等案例完全一致。
- 捲動同步：textarea 與覆蓋層 `scrollTop` 相同。
- 日期氣泡「改為今天」「指定日期…」套用後，文字與顏色同步更新，氣泡保持關閉，焦點仍在 textarea。
- 深色主題下三色仍可辨識；英文語系下按鈕與日期顏色皆正常。
- `node --check` 通過。
