## 时间

## 任务
让搜索栏在滚动时固定在画面中（类似标题栏的 sticky 效果）

## 问题描述
用户反映当页面滚动时，搜索栏会被滚动出画面，希望它能像标题栏一样持续留在画面中。

## 解决方案
给 `.filter-bar` 添加 CSS `position: sticky` 属性：
- `position: sticky` - 实现粘性定位
- `top: 60px` - 固定在标题栏下方（约60px高度）
- `z-index: 90` - 位于标题栏（z-index: 100）下方

## 改动文件
- `index.html` - 修改 `.filter-bar` CSS 样式

## 总结
搜索栏现在会像标题栏一样，在滚动时固定在画面顶部下方位置。
